# Contributing

This is the `earnerbaymalay/earnerbaymalay` profile repo:

- `README.md` is what GitHub renders on the profile page.
- `index.html` only redirects old `earnerbaymalay.github.io/earnerbaymalay/` links to the site.

The site itself lives in [earnerbaymalay/earnerbaymalay.github.io](https://github.com/earnerbaymalay/earnerbaymalay.github.io).
This repo must keep the name `earnerbaymalay`, or GitHub stops showing the README on the profile.

## Making changes

1. Edit `README.md`. Keep the Nocta style: dark-only, Geist / Geist Mono, accent `#d4a843`.
2. Preview `README.md` in any GitHub-flavoured Markdown viewer.
3. Check links and widget URLs still load.
4. Commit with a [Conventional Commit](https://www.conventionalcommits.org/) message, e.g. `fix(readme): ...`, then push to `main`.

Do not replace `README.md` with the shared project template; it is the profile itself.
