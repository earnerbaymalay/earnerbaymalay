# Contributing

This is the `earnerbaymalay/earnerbaymalay` profile repo:

- `README.md` is what GitHub renders on the profile page.
- `index.html` is the GitHub Pages site (`earnerbaymalay.github.io`, see `CNAME`).

Both are static files with no build step and no dependencies.

## Making changes

1. Edit `README.md` and/or `index.html`. Keep the Nocta style: dark-only, Geist / Geist Mono, accent `#d4a843`.
2. Preview `index.html` by opening it in a browser; preview `README.md` in any GitHub-flavoured Markdown viewer.
3. Check links and widget URLs still load.
4. Commit with a [Conventional Commit](https://www.conventionalcommits.org/) message, e.g. `fix(readme): ...`, then push to `main`. Pages redeploys automatically.

Do not replace `README.md` with the shared project template; it is the profile itself.
